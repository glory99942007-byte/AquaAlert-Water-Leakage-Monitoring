About AquaAlert

A community-powered digital solution designed to improve water conservation through faster leakage reporting and complaint tracking.

🌊

Our Mission

Water leakage is a serious problem that can waste valuable drinking water. AquaAlert provides a simple reporting interface where citizens can submit complaints, identify affected locations and follow their resolution status.

Project Technologies

HTML5 – Web page structure
CSS3 – Responsive user interface
JavaScript – Application functionality
LocalStorage – Browser data persistence
